# Proposal

## Why
Support the requested Gauntlet 3D cooperative game on the shared server.

## What Changes
Add authoritative dungeon simulation and an isolated four-seat room using existing lifecycle and shared client.

## Capabilities
### New Capabilities
- gauntlet-network: Dungeon gauntlet-network behavior.
### Modified Capabilities
None.

## Impact
New server room/simulation, registry, integration tests and release documentation. Existing games remain compatible.
